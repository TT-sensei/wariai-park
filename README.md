# 割合パーク（試作）

小学5年・算数の「割合」を練習する学習アプリの試作です。

## 学習の考え方

割合の肝は、「もとにする量を『1』とみて、そこから矢印を引っ張ってかける」ことです。
すべてのモードの図を二重数直線で統一し、次の表現にしています。

- 上段＝量、下段＝割合を対応させる
- もとにする量の真下に「1」をはっきり示す（丸印つき）
- 「1」の位置から比べる量の位置まで、矢印がアニメーション（約1秒）で伸び、ラベル「×0.4」のように「かける割合」が付く
- 割合が1より大きい問題では、矢印が「1」の位置を越えて右へ伸びる

問題表示時と正解・解説表示時の両方でアニメーションが再生されます（画面を描き直すたびに再生）。
外部ライブラリは使わず、SVG＋CSSアニメーションだけで実装しています。

## モード（各モードに担当ナビキャラ）

1. わりあいをもとめる（そら）：もとにする量を言葉で選ぶ → 式を選ぶ → 小数で入力、のステップ式。5問（割合が1より大きい問題を1〜2問含む）
2. くらべる量をもとめる（りく）：式を選んで（もとにする量×割合）入力。割合の提示は小数・％・歩合を混ぜる。5問
3. もとにする量をもとめる（かい）：式を選んで（比べる量÷割合）入力。割り切れる数だけ。5問
4. よみかえ（つき）：小数・％・歩合の読み替えを3択で。その場で解説。8問
5. くらべる（なみ）：AとBそれぞれの割合を求めてから、どちらが大きいか選ぶ。5問

## 学習サイクル

- 途中のステップで間違えた問題は、端末内（localStorage）に記録される
- 「とっくん」：記録された問題そのものを再出題し、間違えずに解けたら記録から消える（克服）。敵・HP・タイマーは入れていない
- 「学習の記録」：モードごとの実施回数・解いた数・正解数・正答率、残っている間違いの数、バッジを表示
- バッジは努力・達成を認めるものだけ（モード初クリア、とっくん克服1/5/10件、通算正解10/30/60問、全モードクリア）

## 数値の扱い

- 割合は内部で「％の整数 P」（例：0.4 → 40）として扱い、入力も「100倍した整数」に変換してから比べるため、浮動小数点の誤差で正誤判定がずれない
- 問題はすべて、割合・比べる量・もとにする量が割り切れる組み合わせだけを生成する（答えは小数第2位まで）

## 保存キー（localStorage）

- `wariaiPark.mistakes.v1`：間違えた問題の記録（再出題に必要な情報を含む）
- `wariaiPark.stats.v1`：モードごとの成績・通算正解・克服数
- `wariaiPark.settings.v1`：音 ON/OFF
