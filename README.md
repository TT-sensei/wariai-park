# 割合ステップ

小学5年・算数「割合」の考え方を、二重数直線と段階的な問題で練習する学習アプリです。

## 学習の土台

割合の学習では、まず「もとにする量」を1とみます。

- 二重数直線の上段は「量」、下段は「割合」
- もとにする量の真下に「1」を置く
- 割合が1より小さいとき、比べる量の印は「1」より左側にくる
- 割合が1より大きいとき、比べる量の印は「1」より右側にくる
- 児童が印の位置を予想してから、二重数直線の対応する位置・矢印を表示する
- 正解・解説では、隠していた値も含めて図を完成させる
- どのモードでも、問題の最初に「1とみる量（もとにする量）」を児童が自分で選ぶステップがある。間違えたら理由のヒントを見て選び直せる
- 矢印は問題のタイプごとに1本だけ表示し、向きと演算が対応する。比べる量を求めるときは「1」から比べる量へ伸びる「×割合」、割合を求めるときは比べる量から「1」へ向かう「÷もとにする量」、もとにする量を求めるときは比べる量から「1」へ戻る「÷割合」

問題に取り組む前に「100人のうち40人」を例に、図の見方を確認できます。

## 6つの練習モード

1. **わりあいをもとめる（そら）**：もとにする量を見つける → 比べる量の印の位置を予想する → 式を選ぶ → 小数で答える。矢印は比べる量から「1」へ向かう「÷もとにする量」で、割合がわり算で生まれることを示します。100％や100％を超える問題も含みます。
2. **くらべる量をもとめる（りく）**：もとにする量を見つける → 比べる量の印の位置を予想してから、もとにする量に割合をかけて求めます。矢印は「1」から比べる量へ伸びる「×割合」です。
3. **もとにする量をもとめる（かい）**：もとにする量を見つける → もとにする量の印が比べる量の印のどちら側にくるか考え、比べる量と割合から逆算します。矢印は比べる量から「1」へ戻る「÷割合」です。
4. **よみかえ（つき）**：小数・％・歩合の相互変換を練習します。同じセット内で問題と選択肢が重ならないようにしています。100％（1、10割）も扱います。
5. **くらべる（なみ）**：まず実際の数の大きさを比べ、その後、A・Bそれぞれの「1とみる量」を見つけてから、それぞれの割合を求めて比べます。実際の数と割合で大小関係が逆になる場面を、毎回少なくとも1問含みます。
6. **3つの用法ミックス（さく）**：割合・比べる量・もとにする量を求める問題を混ぜ、「1とみる量」と何を求める問題かを自分で判断してから、式と答えを考えます。矢印の向きも、求める量に合わせて変わります。

## ナビキャラに計算をたのむ

考え方（「1とみる量」と式）は児童が自分で考え、計算だけをナビキャラに肩代わりしてもらえる仕組みです。

- 数値を入力するステップに、そのモードの担当ナビキャラのボタン「◯◯に 計算を たのむ」があります。式を選ぶステップでは使えません。
- 押すと、ナビキャラが計算の数値結果だけを見せます（例：「0.4」だよ）。計算過程の説明や、式の立て方のヒントは出しません。
- 答えは自動入力されません。見た答えを、児童が自分で入力して答え合わせします。たすけてもらったステップで写し間違えても、「まちがえた」扱いにはなりません。
- たすけてもらった問題の扱い：考え方は合っているので、誤答として記録せず、とっくん送りにもなりません。ただし「どの段階も誤答せず自力で解けた」数には数えません（合格・マスター判定の対象外）。とっくん中にたすけてもらった問題は、克服したことにもなりません。
- 使った回数は成績に記録され、学習の記録で「ナビに計算をたすけてもらった問題」として区別して表示します。

## しきだけ れんしゅう

計算まで行わず、「1とみる量を決める → 式を選ぶ」だけを繰り返す速いドリルです。ホームの入り口カードから始めます。

- 出題は「わりあいをもとめる」「くらべる量をもとめる」「もとにする量をもとめる」の3タイプを混ぜて10問。タイプの見分けも含みます。
- 1問の流れ：場面と二重数直線（答えは隠す）→「1とみる量」を選ぶ → 式を選ぶ → その場で正解・不正解と解説（矢印の向きと対応させて表示）→ 次へ。数値の答えは入力しません。
- 結果画面で正解数を出します。このドリルの結果は、各モードの合格・マスター判定には影響せず、誤答しても間違い記録（とっくん）には入りません。
- 実施回数と正解数の累計だけを成績に記録し、学習の記録とホームのカードで見えるようにしています。

## 何度も挑戦する

- 同じモードを何度でも繰り返し練習できます。
- 次のセットを作るとき、直近に出題した問題をできるだけ避けます。
- 出題履歴は端末内に保存され、ブラウザーを閉じても引き継がれます。
- 問題の数値・場面も増やしました。「わりあいを求める」は41場面、「くらべる量を求める」「もとにする量を求める」は15場面と割合22種類（0.2〜2）の組み合わせ、「くらべる」は22場面、「よみかえ」は4つの変換形式それぞれ24種類の数値を用意しています。
- 「くらべる」は、実際の数の大小と割合の大小が逆になる問題を、毎回必ず1問以上含みます。

## 誤答から学び直す

- 誤答した段階に応じて、考え方のヒントを表示します。
- どこかの段階で誤答した問題は、端末内に記録します。
- **とっくん**では、記録した問題に再挑戦します。誤答せずに解き切ると、その問題は記録から消えます。
- 解説では式だけでなく、「なぜその式になるのか」という考え方も振り返ります。
- 空欄のまま答え合わせをしても、誤答として記録しません。

## 合格・マスターの判定

1回の練習を最後まで解いたことと、理解して解けたことを分けて記録します。

- 各モードの問題を最後まで解くと「挑戦済み」です。
- 5問のモードは4問以上、6問のミックスは5問以上、8問の読み替えは7問以上を、どの段階も誤答せずに解けると「合格」となり、そのモードの「マスター」を獲得します。
- 一度獲得したマスターは、次の練習で結果が下がっても保持します。
- 学習記録の正答率は、誤答せず最初から解けた問題の割合です。

## 数値の扱い

- 割合は「％の整数 P」（例：0.4 → P=40）として扱います。
- 入力は100倍した整数に変換してから比べるため、浮動小数点の誤差で正誤判定がずれません。
- 問題は、答えが小数第2位までで表せる組み合わせを中心に生成します。

## 保存

- `wariaiPark.mistakes.v1`：誤答問題の記録
- `wariaiPark.stats.v1`：モードごとの成績・マスター状況・通算正解・克服数、「ナビに計算をたすけてもらった問題」の数、しきだけ れんしゅうの実施回数・正解数
- `wariaiPark.settings.v1`：音のON/OFF
- `wariaiPark.recent.v1`：モードごとの直近の出題履歴（重複を減らすため）

記録はブラウザーのlocalStorageに保存されます。端末やブラウザーが変わると共有されません。
