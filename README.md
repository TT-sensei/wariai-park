# 割合パーク

小学5年・算数「割合」の考え方を、二重数直線と段階的な問題で練習する学習アプリです。

## 学習の土台

割合の学習では、まず「もとにする量」を1とみます。

- 二重数直線の上段は「量」、下段は「割合」
- もとにする量の真下に「1」を置く
- 「1」の位置から比べる量の位置まで矢印を伸ばし、「×割合」を表す
- 割合が1より大きいときは、矢印が「1」を越えて伸びる
- 問題に取り組む前に、100人のうち40人を例に図の見方を確認できる

読み替えモードは数直線を使わず、小数・百分率・歩合の関係に集中します。

## 5つの練習モード

1. **わりあいをもとめる（そら）**：もとにする量を選ぶ → 式を選ぶ → 小数で答える。割合が1より大きい問題も含みます。
2. **くらべる量をもとめる（りく）**：割合を小数・％・歩合で示し、もとにする量に割合をかけて求めます。
3. **もとにする量をもとめる（かい）**：比べる量と割合から、もとにする量を逆算します。
4. **よみかえ（つき）**：小数・％・歩合の相互変換を練習します。同じセット内で問題と選択肢が重ならないようにしています。
5. **くらべる（なみ）**：2つの割合をそれぞれ求めてから比較します。濃さ・成功率・割引率・読書・参加率・目標達成率・売上の伸びなど、場面を広げています。

## 誤答から学び直す

- 誤答した段階に応じて、考え方のヒントを表示します。正解をそのまま見せるのではなく、どこに注目するかを促します。
- どこかの段階で誤答した問題は、端末内に記録します。
- **とっくん**では、記録した問題に再挑戦します。誤答せずに解き切ると、その問題は記録から消えます。
- 解説では式だけでなく、「なぜその式になるのか」という考え方も振り返ります。
- 空欄のまま答え合わせをしても、誤答として記録しません。

## 合格・マスターの判定

1回の練習を最後まで解いたことと、理解して解けたことを分けて記録します。

- 各モードの問題を最後まで解くと「挑戦済み」です。
- 5問のモードは4問以上、8問の読み替えは7問以上を、どの段階も誤答せずに解けると「合格」となり、そのモードの「マスター」を獲得します。
- 一度獲得したマスターは、次の練習で結果が下がっても保持します。
- 学習記録の正答率は、誤答せず最初から解けた問題の割合です。

## 数値の扱い

- 割合は「％の整数 P」（例：0.4 → P=40）として扱います。
- 入力は100倍した整数に変換してから比べるため、浮動小数点の誤差で正誤判定がずれません。
- 問題は、答えが小数第2位までで表せる組み合わせを中心に生成します。

## 保存

- `wariaiPark.mistakes.v1`：誤答問題の記録
- `wariaiPark.stats.v1`：モードごとの成績・マスター状況・通算正解・克服数
- `wariaiPark.settings.v1`：音のON/OFF

記録はブラウザーのlocalStorageに保存されます。端末やブラウザーが変わると共有されません。
